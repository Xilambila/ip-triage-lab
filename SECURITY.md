# Safe use and vulnerability reporting

This lab performs offline classification only. Do not commit real incident logs, operational addresses, API keys, employee information or customer artifacts. Public examples use documentation address space and synthetic identities.

Success output contains the input address. Command history and terminal captures may also retain it; use only synthetic inputs for public demonstrations.

Use GitHub private vulnerability reporting if enabled. Otherwise use the professional contact linked in the maintainer's profile to arrange a private channel. Never disclose a live secret in a public issue. There is no production service or support SLA associated with this repository.
